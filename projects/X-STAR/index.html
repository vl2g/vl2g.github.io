Dikshant Sharma1,Prateek1,Anand Mishra1

1Indian Institute of Technology Jodhpur

Paper soon Code Dataset Models

Abstract

Scene text provides distinctive cues for finding a place, storefront or institution, but the words in an image and the language of a search query may differ. We introduce X-STAR, a benchmark for cross-lingual scene text-aware image retrieval with 6,449 images and queries in 13 languages. Our model, CoLITE-CLIP, combines frozen CLIP visual features with embeddings of recognised scene-text lines through bidirectional co-attention. Token-level late interaction then matches the query to the fused image representation. Non-English queries and scene text are mapped to English through upstream translation. On the X-STAR test split, CoLITE-CLIP achieves 46.5% Recall@1, compared with 24.6% for the global CLIP ViT-B/32 baseline, averaged over all 13 query sets. The split’s known exact-image overlap is documented alongside the results.

Overview of CoLITE-CLIP

Image features are represented by 50 CLIP ViT-B/32 tokens. Up to 40 English OCR-line embeddings, padded with a learned null token, are fused with them through 11 bidirectional cross-attention blocks. ColBERT-style MaxSim scores the query tokens against the 90-token image bank. The fusion module is trained with a symmetric InfoNCE loss, first on TextCaps and then on X-STAR.

The X-STAR Dataset

Download annotations · CC BY-SA 4.0 · Images acquired separately

The primary benchmark uses the split. Images come from Bharat Scene Text Dataset (5,949) and RCTW-17 (500). Each record has a query in English, Assamese, Bengali, Gujarati, Hindi, Kannada, Malayalam, Marathi, Odia, Punjabi, Tamil, Telugu and Chinese.

Quantitative Results

Results on the X-STAR benchmark, the primary release setting. Recall@K (%) is macro-averaged over all 13 query sets: 16,757 queries, each ranked against the complete 1,289-image test gallery.

Primary benchmark: X-STAR test split
Method R@1 R@5 R@10
CLIP ViT-B/32 24.6 42.8 52.0
CoLITE-CLIP 46.5 65.8 73.0

These scores are verified evaluations of the existing main checkpoint and cached features, not a complete rerun from raw images. Equal scores retain the fixed gallery order. Integrity note: the split contains byte-identical images across training, validation and test. Selecting it as the primary benchmark does not remove that limitation.
