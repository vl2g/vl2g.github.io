X-STAR: Cross-Lingual Scene Text-Aware Image Retrieval

A multilingual scene-text image retrieval dataset and benchmark

Dikshant Sharma1,Prateek1,Anand Mishra1

1Indian Institute of Technology Jodhpur

Paper soon Code Dataset Models

Abstract

Scene text provides distinctive cues for finding a place, storefront or institution, but the words in an image and the language of a search query may differ. We introduce X-STAR, a benchmark for cross-lingual scene text-aware image retrieval with 6,449 images and queries in 13 languages. Our model, CoLITE-CLIP, combines frozen CLIP visual features with embeddings of recognised scene-text lines through bidirectional co-attention. Token-level late interaction then matches the query to the fused image representation. Non-English queries and scene text are mapped to English through upstream translation. On the X-STAR test split, CoLITE-CLIP achieves 46.5% Recall@1, compared with 24.6% for the global CLIP ViT-B/32 baseline, averaged over all 13 query sets.

The X-STAR Dataset

X-STAR contains 6,449 images and 83,837 queries in 13 languages. It supports cross-lingual scene-text-aware retrieval: the language of a query can differ from the text visible in the image.

CoLITE-CLIP

Our retrieval model combines frozen CLIP features with scene text through bidirectional co-attention, then ranks images using token-level late interaction.
